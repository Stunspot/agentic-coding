# Agentic Coding project site

This directory is the static GitHub Pages source for **Agentic Coding**.

- `index.html` provides the semantic, text-first landing page.
- `style.css` provides responsive, keyboard-visible, reduced-motion-aware presentation.
- `assets/agentic-coding-hero.png` is a generated 1600×900 PNG stored in the repository.
- `.nojekyll` asks GitHub Pages to serve the directory directly.

The site uses no JavaScript, analytics, webfont download, framework, or coded SVG artwork. It presents maintained adapter `0.1.1`, with the historical `1.0.0` contest snapshot kept as provenance. Nova edition releases own installation and activation. Source-site checks do not establish model behavior.
